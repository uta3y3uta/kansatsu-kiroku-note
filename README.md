# 観察記録ノート

教室での子供の様子を，音声入力でかんたんに残せるWebアプリです。

## 機能
1. **音声入力による観察記録** — マイクボタンを押すだけで話した内容を文字起こし（Web Speech API・日本語）。
2. **タイムスタンプの自動付与と一覧化** — 保存と同時に日時が記録され，「記録一覧」タブに新しい順で並びます。
3. **子供の名前ごとの自動分類** — 名前欄に入力した子供ごとに，「子供別」タブでまとまって表示されます。複数名（「，」「、」「,」「スペース」区切り）に対応。
4. **ExcelとGoogleスプレッドシートへの書き出し** — `.xlsx` 形式で直接ダウンロード，またはGoogleスプレッドシートで開けるBOM付きCSVで書き出せます。

## 使い方
1. `index.html` をChromeまたはEdgeで開きます（音声入力にはマイクの許可が必要です）。
2. **録音**タブで，必要なら子供の名前を入れて，マイクボタンを押して話します。
3. もう一度押すと停止。文面を確認して「この記録を保存」。
4. **記録一覧**タブで全記録の確認・検索・編集・削除ができます。
5. **子供別**タブで，名前ごとの記録がまとまって見られます。
6. 一覧タブの「Excelに書き出し」「CSV」ボタンで外部ファイルに書き出せます。

## ファイル構成
- `index.html` — 画面構造
- `style.css` — 見た目（やわらかい配色）
- `app.js` — 録音・保存・分類・書き出しのロジック

## 補足
- 記録はブラウザの `localStorage` に保存されます（端末・ブラウザごと）。バックアップは書き出し機能で。
- 音声入力に対応しないブラウザでは，テキスト欄に直接入力できます。
